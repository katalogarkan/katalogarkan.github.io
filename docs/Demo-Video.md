## 2. Script & Shot List (90 Seconds)

## 3. Recording Checklist

**Before Recording:**
- [ ] Close notification apps (Slack, WhatsApp, etc.) so they don't appear on screen.
- [ ] Use Chrome/Edge in Incognito mode (to keep the view clean of bookmarks).
- [ ] Set the screen resolution to 1920x1080.
- [ ] Make sure the internet is stable (so no loading spinners appear).

**While Recording:**
- [ ] Use OBS Studio or Loom.
- [ ] Move the cursor slowly and smoothly.
- [ ] Pause for 1 second after each click (makes editing easier).
- [ ] Do not scroll too quickly.

---

## 4. Editing & Export

- **Software:** DaVinci Resolve (free) or CapCut.
- **Music:** Use royalty-free instrumental music at low volume so the voiceover stays clear.
- **Export:** MP4 (H.264), 1080p, 30fps.
